# Spooky-Burst

A Halloween arcade shooter made in Godot 4. The game is in `spooky burst/the-spooky-burst/`; see its README for controls and how it plays.

## How to launch (Windows)

1. Clone this repo.
2. Double-click `spooky burst/Play.bat`.
3. If Godot isn't set up yet, it asks you to pick:
   - **1** downloads Godot 4.3 for you (free, about 57 MB)
   - **2** lets you pick a Godot you already have (it remembers it)
4. The first run imports the sounds, then the game starts.

You can also open `spooky burst/the-spooky-burst/project.godot` in Godot and press F5.
