# Spooky-Burst

A Halloween arcade shooter made in Godot 4. The game is in `spooky burst/the-spooky-burst/`; see its README for controls and how it plays.

## How to launch (Windows)

1. Clone this repo.
2. Download Godot 4.3 or newer from [godotengine.org](https://godotengine.org/download/windows/) (the standard version, not .NET).
3. Unzip it into `spooky burst/godot/` (so the folder holds `Godot_v4.x-stable_win64.exe`). Git ignores this folder, so Godot never gets committed.
4. Double-click `spooky burst/Play.bat`. The first run imports the sounds, then the game starts.

Already have Godot somewhere else? Set a `GODOT` environment variable to its folder or `.exe` instead of step 3, or open `spooky burst/the-spooky-burst/project.godot` in Godot and press F5.
